# Touchline Africa ⚽

**The world of football, in one place.**

A responsive football editorial website with an African perspective and global coverage.

## What's included

- Responsive homepage with editorial hero and featured sections
- Latest stories grid with category filters and search
- African football spotlight
- Global football region cards
- Match centre placeholder for future fixtures and live scores
- Newsletter sign-up preview
- Mobile navigation and responsive layouts

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Important launch notes

- The current stories are editorial sample content to establish the design; they are not a live news feed.
- Match schedules and live scores are intentionally marked as coming soon. Connect a trusted football data provider before publishing live match information.
- The newsletter form is a front-end preview. Connect an email marketing service and configure consent/privacy wording before collecting addresses.
- Replace sample story copy and imagery with licensed editorial assets and verified reporting.
- Add a privacy policy, contact page, editorial standards and social links before public launch.

## Customisation

- Edit story cards and page structure in `index.html`.
- Change colours, typography and layout in `styles.css`.
- Update navigation, filtering and form behaviour in `script.js`.
