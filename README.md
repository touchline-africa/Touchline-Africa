# Touchline Africa

**The global game. The African heartbeat.**

A responsive, static football editorial homepage built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Files
- `index.html` — page structure and homepage content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and small interactions

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Select **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then select **Save**.
5. Wait for the Pages deployment to finish. The expected project URL is:
   https://touchline-africa.github.io/Touchline-Africa/

## Before public launch
- Replace the sample editorial cards with verified, up-to-date reporting.
- Connect a licensed football data provider before displaying live scores, standings or fixtures.
- Connect a mailing-list provider before collecting newsletter subscriptions.
- Add real editorial photography that you have permission to use.

This is a static front-end starter. It does not currently fetch live football data or send newsletter emails.
